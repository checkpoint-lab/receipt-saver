# 領収書セーバー（非公式）

Amazon.co.jpの領収書ページ（「印刷可能な注文概要」）に、**日付・取引先・金額のファイル名案**を出し、ボタンを押すと、そのファイル名でPDFを保存できる印刷画面を開く Chrome 拡張です。保存した書類は、台帳に記録され、CSVで書き出せます。

**非公式です。Amazonとは関係がありません。** 保存の操作は、すべてあなたが行います。

## 何をするか

| 機能 | 内容 |
|---|---|
| ファイル名の案 | 領収書ページから、注文日・ご請求額（なければ注文合計）・出品者名・注文番号を読み取り、`20231220_出品者名_5500.pdf` の形の保存名を出す。取引先は、パネルで直せる |
| PDFとして保存 | 「この名前でPDFを保存（印刷画面を開く）」を押すと、ページのタイトルを保存名にして、ブラウザの印刷画面を開く。送信先で「PDFに保存」を選ぶと、この名前が入る |
| 取引先の決め方 | 領収書ページの「販売:」の出品者名が**1種類ならその名前**。複数の出品者がいる場合や、読み取れない場合は「**Amazon**」を入れる。いずれも、パネルで直せる |
| 台帳 | 保存した書類の、日付・取引先・金額・注文番号・書類の種類・保存名・保存日時を、このブラウザの中に記録する（無料は50件まで）。ツールバーのアイコンから、一覧・CSV書き出し・削除ができる |

## 何をしないか

- Amazonへ、追加のリクエストを送りません（開いているページを読むだけです）
- ページの自動巡回、リンクやボタンの自動クリック、フォームの自動入力をしません
- ログイン情報、お届け先（氏名・住所）、支払い方法は、読み取りも記録もしません
- 外部のサーバーへ、何も送信しません（台帳は、ブラウザの `chrome.storage.local` のみ）
- 「電子帳簿保存法に対応」「適格請求書として有効」とは、言いません。ファイル名の付け方が、税務上の要件を満たすかは、税理士等にご確認ください

## 使い方

1. Amazon.co.jp の「注文履歴」で、注文の「領収書等」→「印刷可能な注文概要」を開く
2. 右下のパネルで、日付・金額・注文番号・取引先と、保存名を確認する（取引先は直せます）
3. 「この名前でPDFを保存（印刷画面を開く）」を押す
4. 印刷画面の送信先を「PDFに保存」にして、保存する

## 検証状況（正直に）

実機（Windows・Chrome・Amazon.co.jp、2023年12月の注文1件）で確認できたこと：

- 領収書ページにパネルが出て、日付・金額（ご請求額）・注文番号を、ページと一致して読み取れた
- 保存されたPDFのファイル名が、パネルの保存名と一致した。PDFは1ページで、領収書の内容を含み、パネルは印刷されなかった
- ポップアップに台帳の一覧が出て、CSVを書き出せた

**未確認のこと：**

- Amazonが直接販売した商品、複数の出品者・複数の商品、返金・割引の別パターンの領収書
- 拡張のポップアップの「×」（1行の削除）と「台帳をすべて消す」の、実機での動作
- Chromeのバージョンの違い、Mac・他のOS
- 注文履歴ページでの動作（このバージョンでは、領収書ページのみ）
- 台帳50件の上限に達したときの、実機での動作

画面の作りが想定と違い、読み取れない項目があるときは、推測で埋めず、「読み取れなかった項目」を表示して、保存を止めます。

## 今のバージョンで、対応していないこと

- 「明細書／適格請求書」のPDF（`invoice.pdf`）の名前付け（次のバージョンで検討）
- 複数の注文のまとめ処理
